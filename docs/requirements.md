# 需求规格说明书

## 项目概述
Windows 桌面历史剪贴板管理工具。手动启动后，在系统托盘运行，自动记录用户复制的内容（文字和图片），提供查看、搜索、置顶、删除功能，支持设置存储期限。

## 功能需求

### F1 - 剪贴板监听
- 软件运行时自动监听系统剪贴板变化
- 支持文字内容和图片内容
- 关闭软件时停止监听

### F2 - 历史记录存储
- 按时间降序排列所有复制内容
- 以卡片形式展示，文字显示预览，图片显示缩略图
- 最多保存 200 条记录
- 数据持久化到本地磁盘

### F3 - 存储期限
- 用户可设置保留天数：1天 / 3天 / 5天
- 超过期限的非置顶内容自动清理
- 定时检查 + 启动时检查

### F4 - 置顶功能
- 用户可将重要内容置顶
- 置顶内容排列在列表最上方
- 置顶内容永不过期、不计入数量上限删除

### F5 - 删除功能
- 用户可手动删除任意记录
- 删除时同步清理关联的图片文件

### F6 - 搜索功能
- 实时关键词搜索，过滤文字内容的卡片
- 搜索结果按时间降序排列
- 无匹配时显示空状态提示

### F7 - 再次粘贴
- 点击卡片将内容复制到系统剪贴板
- 用户在其他软件中 Ctrl+V 粘贴
- 复制成功后显示 Toast 提示

### F8 - 全局快捷键
- Ctrl+Shift+V 弹出/隐藏主窗口
- 窗口居中显示，类似 Spotlight 风格
- 仅软件运行时生效

### F9 - 系统托盘
- 托盘图标常驻
- 右键菜单：打开主界面 / 退出
- 左键单击打开主界面

### F10 - 设置面板
- 保留天数选择（1/3/5 天）
- 设置即时生效

### F11 - UI 风格
- 主色调：淡蓝色 (#E3F2FD)
- 简洁直观的卡片式布局
- 置顶卡片有视觉区分

## 非功能需求

- 开机不自启（用户手动启动）
- 窗口关闭按钮最小化到托盘（不退出进程）
- 真正退出只能通过托盘右键「退出」
- 不依赖网络连接
- 所有数据存储在本地

## 用户故事

1. 我在浏览网页时复制了一段重要文字，第二天想找回它 → 打开软件，在列表中看到昨天的复制记录，点击即可再次使用
2. 我截图了一张重要信息，但不小心又复制了其他内容 → 打开软件，找到那张图片缩略图，点击复制回剪贴板
3. 我有一个频繁使用的模板文字 → 将它置顶，每次打开软件都在最上面
4. 我想清理一周前的临时复制内容 → 设置 5 天保留期，旧内容自动消失
