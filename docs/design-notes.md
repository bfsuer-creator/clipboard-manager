# UI 设计规范

## 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 主背景 | `#FFFFFF` | 窗口底色纯白 |
| 卡片背景 | `#E3F2FD` | 淡蓝色，柔和不刺眼 |
| 卡片悬停 | `#BBDEFB` | 稍深蓝，hover 反馈 |
| 主强调色 | `#64B5F6` | 按钮、图标、选中状态 |
| 深色强调 | `#1E88E5` | 按钮 hover、链接 |
| 文字主色 | `#212121` | 卡片标题和正文 |
| 文字次要 | `#757575` | 时间戳、辅助信息 |
| 置顶标记 | `#1976D2` | 置顶卡片左侧竖条 |
| 删除按钮 | `#EF5350` | 删除操作警示色 |
| 分割线 | `#E0E0E0` | 列表项分隔 |
| 阴影 | `rgba(0,0,0,0.08)` | 卡片阴影 |

| 窗口宽 | 420px |

## 字体

- 系统默认字体栈：`-apple-system, BlinkMacSystemFont, "Segoe UI", "Microsoft YaHei", sans-serif`
- 等宽字体（时间戳）：`"SF Mono", "Cascadia Code", Consolas, monospace`

## 动效

| 场景 | 动画 |
|------|------|
| 窗口弹出 | 200ms ease-out，从 0.9 缩放到 1.0 + 淡入 |
| 卡片出现 | 150ms ease-out，从上方滑入 |
| 卡片删除 | 150ms ease-in，向右滑出 + 淡出 |
| 按钮 hover | 150ms，背景色渐变 |
| Toast 出现 | 300ms，从底部滑入，2s 后自动消失 |
